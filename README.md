# Trello MCP Server

A [Cloudflare Worker](https://developers.cloudflare.com/workers/) that exposes Trello board data via the Model Context Protocol (MCP).

## Tools

| Tool | Description |
|------|-------------|
| `list_boards` | List all boards the authenticated user can access |
| `get_lists` | Get lists on a specific board |
| `list_cards` | Get cards within a specific list |
| `check_updates` | Get recent actions/updates on a board |

## Prerequisites

- [Node.js](https://nodejs.org/) 18 or later
- A [Cloudflare](https://dash.cloudflare.com/) account
- A [Trello API key and token](https://developer.atlassian.com/cloud/trello/guides/rest-api/api-introduction/)

## Setup

```bash
npm install
npm run build
```

After building, compiled output appears in `dist/index.js`.

## Local development

Create a `.dev.vars` file in the project root (this file is gitignored):

```
TRELLO_API_KEY=your_key
TRELLO_TOKEN=your_token
```

Start the local worker:

```bash
npm run dev
```

Wrangler prints a local URL (typically `http://localhost:8787`). The worker accepts POST requests only.

## Deploy to Cloudflare

1. Log in to Cloudflare:

   ```bash
   npx wrangler login
   ```

2. Set production secrets (you will be prompted for each value):

   ```bash
   npx wrangler secret put TRELLO_API_KEY
   npx wrangler secret put TRELLO_TOKEN
   ```

3. Build and deploy:

   ```bash
   npm run deploy
   ```

4. Note the deployed URL from the Wrangler output, e.g. `https://trello-mcp-server.<your-subdomain>.workers.dev`.

## Connect in Cursor

Add the worker URL to your Cursor MCP configuration:

```json
{
  "mcpServers": {
    "trello": {
      "url": "https://trello-mcp-server.<your-subdomain>.workers.dev"
    }
  }
}
```

Replace the URL with your actual deployed worker address.

## Scripts

| Script | Command | Description |
|--------|---------|-------------|
| `build` | `tsc` | Compile `src/` to `dist/` |
| `typecheck` | `tsc --noEmit` | Type-check without emitting files |
| `dev` | `npm run build && wrangler dev` | Run locally with hot reload |
| `deploy` | `npm run build && wrangler deploy` | Build and publish to Cloudflare |
